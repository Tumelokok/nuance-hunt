# Security and sensitive data

The current prototype has no server and makes no model API calls. Comparison cards are stored in browser storage on the device that created them. Exported JSON contains the prompts, responses, model names, notes, and ratings entered by the user.

Do not use real personal conversations, health or financial details, credentials, API keys, or private documents as evaluation data. Review every exported file before sharing it publicly.

If you find a security issue after the project is published, do not include secrets or personal data in a public issue. Contact the maintainers privately using the repository's security reporting option.
