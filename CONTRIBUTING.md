# Contributing

Thank you for helping make model evaluations more useful across languages.

## Start with the people who speak the language

Language quality must not be guessed from spelling alone or judged only by an English-speaking reviewer. If a test card includes a language you speak, please say which variety or dialect you reviewed and what kind of feedback you can provide. You do not need to share personal identity details.

## Data and privacy

- Use prompts and reference material you have permission to share.
- Never include private conversations, health or financial details, passwords, API keys, or personal documents.
- Remove names and identifying details from examples before exporting them.
- The prototype stores cards in the browser. Exported files contain the prompt and response text you entered; review them before sharing.
- Do not submit model outputs as human-verified translations unless a fluent speaker has reviewed them.

## Useful first contributions

- Review the rating questions for clarity and bias.
- Improve keyboard access, screen-reader labels, or mobile layout.
- Propose a comparison task that does not depend on personal or sensitive data.
- Document how to record model name, version, and generation settings reproducibly.
- Add an import adapter for a benchmark with a compatible license, with attribution.

For substantial changes, open an issue first so we can discuss the scope and review method.
