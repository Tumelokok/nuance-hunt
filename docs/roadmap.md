# Roadmap

## 0.1 — Local comparison workbench

- Create paired prompt and response cards.
- Record model, language variety, task, source, and human ratings.
- Save to browser storage and export JSON.
- Make the local-only behavior and data risks visible.

## 0.2 — Reproducible result cards

- Publish and document a versioned data schema.
- Record generation settings and prompt relationship (translation or adaptation).
- Add import/export support for selected compatible public benchmarks, with attribution and license checks.
- Add automated checks for the card format and accessible UI.

## 0.3 — Community review

- Invite fluent speakers to revise the rating guide.
- Pilot with a small, consented set of non-sensitive tasks.
- Record reviewer confidence and language variety without requiring real names.
- Publish only individual, attributable cards until a larger methodology is agreed.

## Later

- Optional model adapters, starting with local inference.
- A comparison gallery with explicit sample counts and uncertainty.
- Contributor workflows for adding test cards and translating the interface.

## Not planned for the first releases

- A universal score claiming that one model is best in a language.
- Automated evaluation presented as a replacement for fluent speakers.
- A server that stores user prompts, conversations, or API keys.
- Importing benchmark data without checking its license and attribution requirements.
