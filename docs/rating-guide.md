# Human review guide

This guide is a starting point for a reviewer. The project needs feedback from fluent speakers before treating these dimensions as a stable rubric.

Rate a response only when you can judge it. Leave a dimension blank when you are unsure; blank is not a zero.

## Meaning preserved

Does the response answer the task that was asked? For translation or adaptation, does it preserve the important intent rather than just matching words?

## Factual accuracy

Are checkable statements correct? Use the linked reference when one is provided. If the task is creative or subjective, leave this blank or explain why it applies.

## Naturalness

Would a fluent speaker in the stated variety use this wording in this situation? Note if the response sounds overly formal, regionally mismatched, stilted, or unnatural.

## Scale

- **1** — Major problem; the response is unusable for this task.
- **2** — Several important problems.
- **3** — Mixed; some useful parts and some clear problems.
- **4** — Good; small issues only.
- **5** — Strong for this task and variety.

The scale is descriptive, not a measurement instrument. Do not compare averages across tasks or languages until a validation method and reviewer agreement process exist.

## Record enough context

When possible, include the model name/version, date, generation settings, whether the prompt was translated or adapted, and the language variety reviewed. Do not include a reviewer’s real name unless they explicitly choose to make it public.
