# Research notes

These notes describe the landscape checked while choosing the first project direction. They are pointers for further collaboration, not endorsements or claims that this project is unique.

- **AfroBench** is an open multilingual benchmark for African languages and a range of NLP tasks: <https://github.com/McGill-NLP/AfroBench>.
- **MzansiBench** brings together evaluations across South Africa's official written languages: <https://showcase.sit.uct.ac.za/event/showcase-2026/mzansibench-36>.
- **Multi-Hall-SA** studies hallucination detection in English and four South African languages: <https://aclanthology.org/2026.findings-eacl.330/>.

The project should complement existing research by making paired prompts, response context, and fluent-speaker review easy to inspect and share. Before importing benchmark data, contributors must check its license, attribution requirements, and methodology.

## Open questions

- Which language varieties and use cases should the first community review cover?
- What minimum reviewer experience should be recorded for each task?
- Which rubric dimensions can be applied consistently across languages?
- How should we handle translation versus culturally adapted prompts?
- What sample size is required before an aggregate result is shown?
